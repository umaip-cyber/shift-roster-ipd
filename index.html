จัดตารางเวร

กรอกพนักงาน เลเวล และเงื่อนไขเวร ระบบจะจัดตารางให้อัตโนมัติ — ปรับแก้เองได้ก่อน export

🗓️ ช่วงวันที่

จัดได้ทุกวันไม่มีวันหยุด/ปิดทำการ — ระบบจะจัดเวรให้ครบทุกวันในช่วงที่เลือก

🔀 ประเภทการจัดเวร

👥 รายชื่อพนักงาน + เลเวล

เลเวล 1-4 ใช้สำหรับกติกาคละระดับในแต่ละเวร (ห้ามเลเวล 1 ล้วนขึ้นด้วยกัน) — วันที่ไม่สะดวกกรอกเป็นเลขวันที่ คั่นด้วยจุลภาค เช่น 5,12,20 — ติ๊ก "ห้ามขึ้นเวร N/บ/ด" สำหรับพนักงานที่ตั้งครรภ์หรือไม่สบาย ระบบจะไม่จัดเวร N, บ (15-23 น.) หรือ ด ให้เลย (แต่ยังจัดเวร D และ ช ให้ตามปกติ)

🕐 จำนวนคนที่ต้องการต่อเวร (ต่อวัน)

ระบบจะพยายามจัดให้ครบตามจำนวนที่กรอกในแต่ละเวรทุกวัน — ถ้าวันไหนคนไม่พอจริงๆ จะจัดเท่าที่ทำได้และแจ้งเตือนไว้ให้ตรวจสอบ

⚙️ กติกาที่ระบบบังคับใช้อัตโนมัติ

  • เวร D ติดกันได้ไม่เกิน 3 วัน · เวร N ติดกันได้ไม่เกิน 3 วัน
  • ทำงานติดกัน (รวมทุกเวร D/N/ช/บ/ด) ได้ไม่เกิน 5 วัน ก่อนต้องมีวันหยุด
  • ใครขึ้นเวร ด หรือ N วันก่อนหน้า จะไม่ถูกจัดเวร D หรือ ช ในวันถัดไป (ต้องได้พัก)
  • แต่ละเวรจะคละเลเวลกัน ไม่ให้เลเวล 1 ล้วนขึ้นด้วยกัน (ถ้ามีคนเลเวลอื่นว่างพอ)
  • กระจายจำนวนเวรให้ใกล้เคียงกันในแต่ละคนเท่าที่เงื่อนไขอื่นเอื้ออำนวย

📋 ตารางเวรที่ได้

D (7-19) N (19-7) ช (7-15) บ (15-23) ด (23-7) off

💡 คลิกที่ช่องในตารางเพื่อสลับเวรเอง (วนตามลำดับ D → N → ช → บ → ด → off)
